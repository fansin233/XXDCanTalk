# 会说话的西小电

一款基于 Godot 4.6.1 的手机互动宠物游戏，包含语音复述、商店、背包、旅行和无尽跑酷玩法。

## 打开项目

在 Godot 4.6.1 项目管理器中导入 `会说话的西小电/project.godot`，或直接选择该目录。主场景为 `Scenes/Main.tscn`。

## Android 导出

项目包含 Android 导出预设。导出时需在本机安装匹配 Godot 4.6.1 的 Android 构建模板和 SDK；应用商店发布还需配置开发者自己的签名密钥。生成的安装包保存在本地 `release/` 目录，该目录不纳入源码仓库。
