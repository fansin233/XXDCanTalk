# 会说话的西小电

基于 Godot 4.6.1 的手机竖屏互动宠物游戏。现有 1.0.1 安装包仍是首发版本；商店、背包和旅行玩法已接入项目源码，Android 候选包尚未发布。项目入口是 `Scenes/Main.tscn`。

## 当前可玩内容

- 主界面显示 `Assests/Model/xxd2.gltf`。头部、身体、红色部件和腰带材质已由 glTF 正确引用；待机与跳跃时双臂自然下垂，听到声音时侧头并把一只手抬到耳边，触摸反馈包含捧腹大笑和挠脚动作。这些动作由骨骼程序姿势驱动，仍属原型表现。
- 按住“按住说话”录音，松开后以 1.6 倍速度和音高播放；也可主动打开“自动聆听”，声音超过门槛后开始录音，安静约 0.58 秒后复述。
- 麦克风默认关闭。录音在内存中处理和播放，不上传或保存录音内容。
- 喂食、抚摸、休息会影响饱腹、电量、心情；有效复述和完成小游戏会增加亲密经验与小电星。状态、钱包、背包、旅行、收件箱和图鉴统一保存在 `user://pet_save.json`。
- “玩耍”打开横向无尽跑酷：点击跑道或跳跃按钮越过路障，收集电星和能量电池累积分数；碰撞后可重开或回家结算，最佳分数保存在本机。
- 星星商店可购买 8 种食物、恢复和成长道具；背包按类别查看并使用，免费基础喂食仍保留。
- 旅行有一次免费的快速引导和附近、城市、远方三条路线。西小电离开时仍可在主界面互动；名片、随机附件、稀有保底与归来奖励在出发时固定，关闭游戏后按经过时间补寄。
- 收件箱把阅读与领取附件分开，名片图鉴记录首次内容和重复获得次数，收集 6、12、18 张时生成一次性奖励。
- 新功能采用存档 v2；首次打开会保留旧 v1 存档副本、迁移经验/星星/每日次数，并发放一次 12 星和新手道具。背景音乐与跑酷最高分仍用原设置文件。
- 主界面采用简洁的渐变背景和扁平化竖屏 HUD，设置页可调背景音乐与音效音量并本地记忆；角色笑声使用 `Assests/Audio/NAILONGLaugh.wav`。
- 背景音乐 `Assests/Audio/bgm_sunny_8bit.wav` 是项目内生成的轻快低 bit 循环曲，不依赖外部素材；源代码生成器位于工作区 `tools/generate_sunny_bgm.py`。

## 运行方式

在 Godot 4.6.1 中打开本目录，运行主场景。项目已将 `Scenes/Main.tscn` 设为启动场景，并启用音频输入和竖屏逻辑分辨率。

Android 首发安装包位于工作区 `release/v1.0.1/`，包含 ARMv7 与 ARM64，使用 Godot 调试签名，适合侧载体验；上架应用商店前需要使用开发者自己的发布密钥重新签名。新功能的导出目标暂设为 `release/dev/`，不会覆盖首发 APK。

清理后未被当前场景与脚本引用的旧模型、测试音频和其他素材已移到项目同级的 `unused_assets_archive_v1_2026-09-29/`；`xxd2.gltf` 所需的四张独立贴图保留在 `Assests/Model/` 并随模型导入。归档内容不进入首发安装包。

当前 Godot 4.6.1 项目扫描、脚本编译和隔离用户目录下的主场景启动均通过。Android 候选 APK 已导出至工作区 `release/dev/`，使用 Godot 调试签名；包名、版本、最低/目标 API、ARMv7/ARM64 与 APK 签名均已核对。Android 启动器图标、自适应图标前景和系统启动图标使用 `Assests/Texture/icon.png`，自适应背景使用 `Assests/Texture/icon_background.svg`。商店交易、离线旅程长时间校时、存档故障恢复，以及真机安全区/麦克风/帧率仍需逐项验收。新角色有 88 根骨骼和权重，但模型本身没有动画片段或面部 blend shape；眨眼、口型和正式动画还需制作。首次启用自动聆听或按住说话时才会请求麦克风权限。

## 主要模块

- `Scripts/Main.gd`：房间、场景装配和游戏流程。
- `Scripts/CharacterPresenter.gd`：角色待机和姿势表演。
- `Scripts/VoiceService.gd`：麦克风采集、声音门槛、短时缓存、高音回放和权限流程。
- `Scripts/Core/GameServices.gd`、`GameStore.gd`、`SaveRepository.gd`：服务装配、唯一状态、原子保存与 v1→v2 迁移。
- `Scripts/Data/Catalog.gd` 与 `Data/*.json`：商品、路线、奖励、名片内容和占位图配置。
- `Scripts/Services/`：商店、物品使用、旅程生成/离线推进、邮件和奖励结算。
- `Scripts/PetState.gd`：现有照顾与成长入口的兼容适配层，不再单独写存档。
- `Scripts/HUD.gd`：竖屏主界面与触摸交互。
- `Scripts/FeatureOverlay.gd`：商店、背包、旅行、收件箱和图鉴面板。
- `Scripts/Minigame.gd`：横向无尽跑酷、障碍和道具、分数及结算界面。

主材质贴图由 glTF 导出并随模型导入；4096×4096 的腰带贴图通过 Godot 纹理导入限制到 2048 并启用 VRAM 压缩和 mipmap，源 PNG 保持不变。其他头部/身体贴图为 1024×1024。实际发行设备上的纹理格式、内存和画质仍需检查。
