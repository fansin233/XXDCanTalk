# 商店、背包与出行实现状态

更新日期：2026-09-29  
工程：`会说话的西小电`（Godot 4.6.1）

## 已接入

- `SaveRepository` 负责 `user://pet_save.json` 的版本 2 读取、候选恢复、临时文件提交、备份轮换和损坏主存档隔离。旧 v1 数据升级前另存为 `pet_save.pre_v2.json`。
- `GameStore` 是钱包、物品、属性、旅行、邮件和图鉴的唯一写入入口。交易先改完整副本，再提交一次；请求回执保留最近 256 条。
- 旧 `PetState` 改成兼容适配层。免费喂食、抚摸、休息、复述和跑酷奖励与新经济数据共用同一存档。
- 新档和 v1 升级档各发放一次 12 星、饭团×2、野餐便当×1。礼包标记和奖励在同一交易中提交。
- 配置表覆盖 8 种商品、6 种纪念品、3 条常规路线、6 个地点、18 张名片模板、收集奖励和快速引导旅程。导出预设已包含 `Data/*.json`。
- 商店购买会校验目录版本、数量和余额；背包使用会在提交时重新计算饱腹、电量、心情和经验的实际增量。免费基础喂食仍可从背包面板使用。
- 常规旅行在出发交易中生成并保存全部时间、名片文字、目的地、稀有度与奖励。每秒低频结算到达节点；后台通过 UTC 秒补进度，前台用单调时钟。旅行不会自动续行，也不影响主界面的照顾、跑酷与语音互动。
- 邮件阅读、附件领取、全部领取、重复领取保护、名片图鉴、首次收集奖励和归来确认已经接入。
- HUD 增加商店、背包、旅行、收件箱和图鉴入口。设置、功能页、笑声和跑酷使用可叠加的语音暂停令牌。
- Android 导出路径移至 `release/dev/会说话的西小电-dev.apk`，避免后续开发包覆盖 `release/v1.0.1/` 首发包。

- 主场景在隔离的 Windows 用户数据目录启动成功；生成的隔离存档为 schema v2，包含正确的一次性礼包。真实的游戏用户数据目录没有参与这次启动检查。
