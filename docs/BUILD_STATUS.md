- 添加喂食/休息状态和本地 JSON 存档。
- 添加按住说话和主动开启的自动聆听。语音仅在当前会话内存处理；自动模式采用前置缓存、音量阈值、静音结束检测和 12 秒上限；复述使用 1.3 倍 pitch_scale。

- Godot 4.6.1 桌面启动检查完成：主场景可启动，MCP 调试输出无脚本或场景错误。项目当前有 1 个场景、6 个脚本。
- 默认切换为 Compatibility 渲染器，让 Android 使用 OpenGL ES 3.0，优先覆盖更多旧设备。
